# Étape 2 — Jeu analytique NUTS 3 allemand

## Résultat produit

Créer une table, une ligne par région NUTS 3 allemande, contenant :

`nuts3_id`, `nuts3_name`, `population`, `industrial_site_count`, `filter_method`, `exposure_index`, `population_index`, `priority_score`, `data_status`.

`filter_method` vaudra soit `secteurs PFAS associés`, si le champ secteur validé à l’étape 1 permet le filtrage, soit `tous sites industriels — secteur non exploitable` dans le cas contraire.

## Méthode

- Conserver uniquement les sites industriels allemands avec coordonnées valides.
- Rattacher chaque site à une région NUTS 3 : utiliser le code NUTS fourni par le jeu industriel s’il est présent et valide ; sinon, faire une jointure spatiale point-dans-polygone avec les limites NUTS 3.
- Compter les sites par région. Le score d’exposition repose sur ce nombre, non sur une densité, afin de rester simple et cohérent avec les deux sources demandées.
- Joindre la population Eurostat de la même maille NUTS 3 ; conserver les régions même lorsqu’une donnée est absente, avec un statut explicite.
- Normaliser séparément les deux dimensions sur 0–100 :
  - `exposure_index = 100 × sites_de_la_région / maximum_des_sites`
  - `population_index = 100 × population_de_la_région / population_maximale`
- Calculer le score avec la moyenne géométrique, choisie pour valoriser les régions élevées sur les deux dimensions :  
  `priority_score = √(exposure_index × population_index)`

Une région sans site recensé reçoit donc un score nul ; une région avec population manquante n’est pas classée et porte un `data_status` visible.

## Contrôles

- Vérifier l’unicité de chaque `nuts3_id`, l’absence de doublons de sites après rattachement et la cohérence du total de sites.
- Vérifier que les codes Eurostat et ceux des limites NUTS correspondent à la même version géographique.
- Conserver dans le jeu analytique le nombre de sites exclus faute de coordonnées ainsi que la méthode de filtrage, pour que l’interface puisse l’expliquer clairement.

## Limite affichée ensuite

Le score classe des zones à investiguer. Le nombre de sites est un proxy de pression industrielle potentielle ; il ne mesure ni la présence de PFAS, ni une contamination, ni un risque sanitaire ou réglementaire.
